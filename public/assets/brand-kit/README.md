# EMERG — Official Brand Kit & Hi-Res Vector Suite

This directory contains the authentic, exact logo of **EMERG** (*Unfold Possibilities*), built directly from the native transparent PNG master with 100% clean alpha channels and infinite-resolution vector SVGs.

---

## Quick Navigation

* 📖 **[Brand Guidelines Document](BRAND_GUIDELINES.md)** – Comprehensive color formulas, clear space, and brand rules.
* 🔤 **[Fonts Kit Directory](fonts-kit/)** – Typography pairing guide, Google Fonts links, and [live font specimen](fonts-kit/font-specimen.html).
* 🖥️ **[Live Brand Showcase](showcase/index.html)** – Browser showcase displaying the exact logo in light, dark, and navbar contexts.
* 📦 **[Vector Masters (`vectors/`)](vectors/)** – Pure infinite-scale SVGs (Exact Full Master, Standalone Symbol, Wordmark, Inverted White, Black).
* 🖼️ **[Ultra High-Res PNGs (`png-high-res/`)](png-high-res/)** – Crystal clear transparent PNGs at 4K UHD (4096px), 2K (2048px), 1024px, and 512px.
* 🌐 **[Web & PWA Icons (`web-icons/`)](web-icons/)** – Production `favicon.ico`, apple-touch-icon, and web manifest.
* 📁 **[Original Master File (`original/`)](original/)** – The immutable original transparent master image.
